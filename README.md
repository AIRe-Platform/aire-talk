# AIRe Talk

This is the source code for AIRe Talk web app. 

It has a simple chat interface and integrations for OpenAI and Ollama for testing and demos.

## Project setup

```sh
npm install
```

It is important that you navigate to `src/services/aire/ai.ts` and configure the AI backend as instructed in the comments.

In future, there will be a `AIRe Hub` web app which you can use to configure your AIRe platform.

### Compiles and hot-reloads for development

Either run the following command or hit F5 in VS Code.

```sh
npm run serve
```

### Compiles and minifies for production

```sh
npm run build
```
